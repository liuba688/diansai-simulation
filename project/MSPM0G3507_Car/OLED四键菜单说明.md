# OLED 四键菜单

按键为低电平有效：

| 按键 | 引脚 | 功能 |
|---|---|---|
| 上 | PB8 | 上移 |
| 下 | PB9 | 下移 |
| 确认 | PB10 | 启动选中任务 |
| 返回 | PB11 | 停车并返回菜单 |

菜单项：

- `BALL VISION`：视觉寻球完整流程；
- `ANGLE HOLD`：静止航向保持；
- `LINE ONLY`：仅灰度巡线；
- `CALIBRATE YAW`：静止重新校准；
- `ODOMETER`：显示累计里程；
- 其余项目预留。

运动任务均有 3 秒安全延迟。返回键短按或长按都会停车。OLED 使用 PA31/PA28
软件 I²C，地址为 `0x3C`。
