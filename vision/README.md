# 视觉开发全流程

本目录汇总本地 MaixCAM 视觉代码与文档，覆盖数据采集、自动/教师辅助标注、YOLO 训练、
ONNX 导出、CVIModel/MUD 转换、MaixCAM 裁切部署，以及 2026 H 题车载平衡滚球的完整实现。

## 目录

- `training/`：钢球数据采集、标注、数据集构建、训练、评估、导出和转换工具，以及已验证模型。
- `h_vehicle_ball_balance/`：H 题 PPR 管内钢球视觉、像素/毫米标定、低延迟运行时、任务实现和台架版本。
- `legacy/`：早期色块、2025 E 题与通用钢珠检测基线，便于回归和对照。

## 推荐流程

```text
MaixCAM 场景采集
  -> 自动标注 / 教师模型复核
  -> 按场景拆分 train/val/test
  -> YOLO 训练与独立场景评估
  -> 导出 ONNX
  -> SG2002 INT8 转换（CVIModel + MUD）
  -> ROI/输入尺寸裁切与 MaixCAM 部署
  -> PPR 管端点归一化和像素到毫米标定
  -> UART 输出位置、速度、置信度和时间戳
  -> H 题滚球闭环、任务状态机与图传录像
```

具体命令、参数、已知限制和实测结果见各子目录 README 与训练报告。

## 数据与生成物策略

仓库保留可复现代码、配置、报告、校准样例、最终部署模型和必要权重。原始采集照片、
生成的数据集、训练缓存、重复转换中间文件及打包产物未提交；它们体积接近 2 GB，且均可
按文档重新生成。本地原始资料仍保存在 `D:\diansai\vision` 和
`D:\diansai\projects\2026_h_vehicle_ball_balance\vision`。

## H 题边界

- 赛道识别只使用红外光电模块，MaixCAM 不识别赛道。
- MaixCAM 负责钢球位置检测和无线图传；图传不进入实时控制闭环。
- 正式控制链为 MaixCAM UART -> MSPM0G3507 -> UART Emm_V5.0 -> ZDT X42S V2.0。
- 坐标以摆杆中心为零点，运行前必须完成端点/三点标定并核对正方向。
