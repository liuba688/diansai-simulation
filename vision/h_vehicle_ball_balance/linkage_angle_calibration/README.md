# X42S 连杆角度标定工具 v0.2.0

本工具只用于脱球标定，不执行钢球闭环控制。适用硬件为
`MaixCAM -> UART1 A19/A18 115200 -> ZDT X42S V2.0 / Emm_V5.0`。

已知几何量：

- 曲柄半径 `r = 35 mm`
- 连杆孔距 `l = 55.5 mm`
- 摆杆有效长度 `L = 253 mm`
- 水平零位曲柄约指向 9 点钟

操作：

1. 拆下钢球，确认硬限位、总电源开关和 UART 共地。
2. 机械调平摆杆，使曲柄接近 9 点钟后上电。
3. 先点 `-20`、`ZERO`、`+20`，确认方向与无干涉。
4. 再点 `-40`、`ZERO`、`+40`。
5. 已确认 `±80 pulse ≈ ±1°` 且机构安全后，长按
   `HOLD 1.5s: UNLOCK +/-100..160` 解锁扩展档。
6. 严格按 `±100 → ±120 → ±140 → ±160` 逐级测试，每一级都先回 ZERO。
7. 每个位置用倾角仪记录实际摆杆角度；`actual motor delta` 只是电机编码器角度。
8. 异常时点击红色 `STOP`，必要时直接切断电机电源。

程序退出和 STOP 都是原地立即停止，不会自动回零。需要回零时必须先点
`ZERO`，确认 `sent=+0` 且机构已回水平，再退出。
