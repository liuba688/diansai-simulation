# MaixCAM H题水管钢球视觉

本目录是可直接由 MaixVision 导入和运行的完整项目。

## 当前模型

```text
pipe_ball_320_v2.mud
pipe_ball_320_v2.cvimodel
```

- 模型：YOLOv8 单类别 `steel_ball`
- NPU输入：`320×320 RGB`
- 转换格式：`cv181x INT8`
- 相机采集：`640×480`
- 推理ROI：`x=[0,640)`、`y=[176,304)`，即 `640×128`
- 缩放方法：`FIT_CONTAIN`，与训练和转换时的 letterbox 一致

程序不会把完整的 `640×480` 画面直接送入模型，而是先截取和训练数据一致的
水管条带。检测坐标会重新映射到完整预览画面。绿色竖线为 `x=320` 中轴线，
黄色矩形为实际推理ROI。

因为正式装置只有一颗钢球，当模型同一帧返回多个候选时，程序只保留置信度最高者，
再进行连续三帧确认和平滑。

## 导入和运行

1. 在 MaixVision 中选择“打开文件夹/项目”。
2. 选择整个 `vision/runtime/` 文件夹，不要只打开 `main.py`。
3. 连接 MaixCAM。
4. 先点击运行，确认模型能够加载并看到黄色ROI和绿色中轴线。
5. 如需安装到设备，使用 MaixVision 的“安装应用/打包应用”功能。

`.mud` 与 `.cvimodel` 必须始终放在 `main.py` 同一目录，且不得混用其他轮次的文件。

## 首次真机检查

- 水管应完整位于黄色ROI内。
- 钢球框应只在黄色ROI内出现。
- 左右移动钢球，终端输出的 `x` 应连续变化且方向正确。
- 暂时不要接入滚球闭环；先记录漏检、误检、坐标跳变和帧率。
- 如果实际机位与采集时不同，应优先调整相机或 `ROI_Y`，不要随意拉伸图像。
