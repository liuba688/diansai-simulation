# MaixCAM H题水管钢球视觉 480×96候选版

本目录是独立的MaixVision可导入项目，不会替换现有的 `vision/runtime/` 正式版本。

## 模型

```text
pipe_ball_480x96_v1.mud
pipe_ball_480x96_v1.cvimodel
```

- 相机采集：`640×480`
- 推理ROI：`x=[0,640)`、`y=[176,304)`，即 `640×128`
- 模型输入：`480×96 RGB`
- ROI和模型均为 `5:1`，直接等比例缩放，不产生上下黑边
- 量化：cv181x INT8

程序逻辑与现有320版相同：黄色框表示推理ROI，绿色线表示 `x=320` 中轴线；
同一帧只保留置信度最高的钢球候选，再做连续三帧确认和坐标平滑。

## A/B测试

分别导入以下两个完整文件夹：

```text
vision/runtime/          # 现有320×320版本
vision/runtime_480x96/   # 本候选版本
```

保持相机、光照、钢球运动和置信度阈值不变，记录：

- 平均FPS和最低FPS
- 完整往返过程中漏检帧数
- 无球时误检次数
- 钢球静止时横坐标峰峰值
- 钢球运动时坐标是否出现跳变

在完成上述真机对比前，不将本候选模型标记为正式版本。
