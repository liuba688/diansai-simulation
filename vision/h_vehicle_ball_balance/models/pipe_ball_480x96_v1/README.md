# pipe_ball_480x96_v1

这是由正式权重 `pipe_ball_320_v2/best.pt` 导出的 `480×96` MaixCAM候选版本，
用于和现有 `320×320` 版本做真机帧率、漏检和坐标抖动对比。它不会替换当前正式模型。

## 输入与数据

- 相机原图：`640×480`
- 推理ROI：`x=[0,640)`、`y=[176,304)`，即 `640×128`
- 模型输入：`480×96`
- ROI与模型输入宽高比均为 `5:1`，无需补黑边
- 权重：与 `pipe_ball_320_v2` 完全相同，仅改变固定导出尺寸

## 转换

- ONNX输入：`1×3×96×480`
- YOLO候选数：945
- 量化：INT8
- 处理器：cv181x
- 校准集：与320版相同的100张四场景均衡ROI图
- 工具链：本地 WSL2 Docker，TPU-MLIR 1.28.1-20260429

ONNX到MLIR、INT8 TPU输出和最终cvimodel模拟器输出比较均通过。

## 使用边界

PC端Ultralytics对非PyTorch矩形ONNX不支持直接运行标准方形验证流程，因此本版本
暂不替换正式模型。必须在MaixCAM上和320版使用同一机位、同一钢球运动过程做A/B测试，
至少比较平均FPS、最低FPS、漏检次数、误检次数和中心坐标抖动。
