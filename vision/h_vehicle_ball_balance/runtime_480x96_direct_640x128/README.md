# MaixCAM 640×128直采候选版

这是独立测试项目，不会替换：

```text
vision/runtime/
vision/runtime_480x96/
```

## 图像链路

```text
相机直接采集 640×128 RGB，目标60 FPS
  -> 直接送入480×96模型
  -> 直接在640×128图像上画框
  -> 显示与MaixVision传输同一张640×128图像
```

本版本不再采集 `640×480`，也不执行 `crop()`。模型仍使用：

```text
pipe_ball_480x96_v1.mud
pipe_ball_480x96_v1.cvimodel
```

## 首次运行必须检查

程序启动时终端应打印：

```text
camera=640x128 requested_fps=60
```

如果驱动没有接受该尺寸，程序会主动报错退出，避免在错误分辨率下误测。

自定义画幅会影响传感器的中心裁切方式，因此必须将画面和原来的 `640×480`
采集版进行对比：

- 水管左右两端是否仍完整可见；
- 黑色零点记号是否仍接近 `x=320`；
- 钢球像素直径是否与训练素材接近；
- 合页或其他结构进入画面的范围是否改变。

如果水平视野明显变宽或变窄，说明 `640×128` 直采与原训练ROI不等价。此时不能仅因
FPS更高就投入闭环，应回到 `runtime_480x96/` 的 `640×480 -> 640×128 ROI` 方案，
或者用直采画幅重新采集少量数据微调模型。

## 帧率对比

连接MaixVision后，让钢球按相同路线运动30秒，记录：

- 平均FPS和最低FPS；
- 漏检帧数；
- 静止钢球横坐标峰峰值；
- 水管两端的识别情况。
