# H 题视觉子系统

## 目标

视觉系统只负责水管上的钢球位置检测、毫米坐标换算、UART 输出和无线图传，不用于
识别赛道。

## 当前运行基线

静态滚球第一问当前保留候选版：

```text
runtime_480x96_direct_low_latency/versions/timed_full_task_v3_1_4_cal435_r3/
```

最新三点标定为 `+50 mm=212、0 mm=324、-50 mm=435`。第 34 次实机在
`4.82 s` 完成，正端最大 `+43.1 mm`、负端最小 `-43.7 mm`。当前仍需重复性验证。

本轮重新训练的目标不是一般环境中的金属球，而是：

```text
固定俯视 MaixCAM
  -> 25 cm 四分 PPR 水管
  -> 直径约 10 mm 钢球
  -> 车辆振动、摆杆约 ±4° 倾斜和不同光照
```

## 画面策略

- 原始采集固定为横向 `640 × 480`。
- 水管左右端尽量接近画面左右边缘，但必须保留端点标定余量。
- 横向像素全部保留，PC 裁剪工具只裁纵向。
- 原始图片永远保留，不能用裁剪结果覆盖原图。
- 纵向 ROI 不能只覆盖静止钢球直径，还必须覆盖水管槽体、约 `±4°` 倾斜产生的端点
  高度变化、车辆振动和少量安装误差。
- 第一批建议同时生成 `160 px`、`128 px` 和 `96 px` 三个纵向版本，比较召回率、
  误检率和 MaixCAM 推理速度后再确定正式输入比例。

## 数据集隔离

训练、验证和测试必须按拍摄场景划分。禁止把同一段连续拍摄的相邻帧随机分散到不同集合，
否则评估结果会虚高。
