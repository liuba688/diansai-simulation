# 接线与安全

## 1. 四键和底盘

| 功能 | MSPM0 引脚 | 说明 |
|---|---|---|
| UP | PB13 | 内部上拉，按下低 |
| DOWN | PB23 | 内部上拉，按下低 |
| OK | PB26 | 内部上拉，按下低 |
| BACK | PB27 | 内部上拉，按下低，软件最高优先级停止 |

底盘 TB6612、编码器、八路红外和 OLED 完整复用 `following_new` 实机接线，不在本工程中
改引脚。若载板版本不同，先按原理图与通断档核对，不可按连接器丝印猜测。

## 2. MaixCAM ↔ MSPM0

| MaixCAM | MSPM0 | 方向 |
|---|---|---|
| A19 / UART1_TX | PA24 / UART2_RX | 相机到主控 |
| A18 / UART1_RX | PA23 / UART2_TX | 主控到相机 |
| GND | GND | 必须共地 |

双方 115200 8N1、3.3 V 逻辑。MaixCAM 独立可靠 5 V/Type-C 供电；载板某些串口座带
12 V，禁止把电源脚接到相机。接线前测出 PA23/PA24 与 GND，只接 TX/RX/GND。

## 3. Type-C 行驶日志

天猛星核心板板载 Type-C/CH340 固定连接 MSPM0G3507 UART0：PA10 为 TX、PA11 为 RX，115200 8N1。直接使用数据线连接电脑，不接外置 USB-TTL。行驶期间日志写入 RAM，停车后通过 Type-C 导出。

## 4. MSPM0 ↔ X42S

适用实物：ZDT X42S V2.0，Emm 固件分支，TTL UART 接口。

`v1.0.3` 将 MSPM0 与 X42S 本次共同上电时的电机位置记为唯一软件水平零点。每次上电前
必须先人工确认水管水平，再给控制系统上电；运行中选择任务不会重新定义零点。Task 3 正常
完成或按 BACK 后会回到该零点。严重通信、视觉或端部故障仍以急停优先，不保证自动回位。

| MSPM0 | X42S TTL | 方向 |
|---|---|---|
| PB6 / UART1_TX | R/A/H（TTL_RX） | 主控到电机 |
| PB7 / UART1_RX | T/B/L（TTL_TX） | 电机到主控 |
| GND | GND | 必须共地 |

X42S 使用独立 10-29 V、建议 12/24 V 3 A 以上电源。MCU 或 MaixCAM 的 3.3/5 V
不得给 X42S 功率端供电。确认实物是 TTL 通讯版本，不能把 RS485 A/B 名称当成 TTL。

## 4. 手册依据与实际命令

依据本地 `ZDT_X42S第二代闭环步进电机用户手册V1.0.4_260401.pdf`：

- 第 40 页：地址/功能码/数据/校验，默认地址 1，默认固定校验 0x6B；成功返回 0x02。
- 第 46 页：运行中的位置命令可被新位置命令打断并平滑更新。
- 第 50 页：使能 `01 F3 AB 01 00 6B`。
- 第 57 页：Emm 标准位置 `FD` 的 13 字节格式。
- 第 58 页：快速位置模式要求具体固件 ≥V2.0.0，本工程未使用。
- 第 60 页：立即停止 `01 FE 98 00 6B`。
- 第 72 页：实时位置 `01 36 6B` 及 Emm 65536 count/圈换算。

本工程位置命令固定速度 30 RPM、加速度档 100、40 ms 最快更新；相对目标模式 0 用于
连续增量，相对当前实时位置模式 2 的 0 脉冲命令只用于上电软件零点锚定。

## 5. 首次上电顺序

1. 拆下钢球，脱开曲柄连杆；确认硬机械限位和总电源急停可用。
2. 只给 MSPM0 上电，确认 OLED 菜单与四键方向。
3. 只连 MSPM0-MaixCAM，逐项确认 MODE_READY/STARTED/BACK，不接 X42S 功率。
4. 连接 X42S TTL 和独立功率电源，电机轴不带连杆；选择 Task 3 准备，确认只锁轴不转。
5. 第二次 OK 后观察电机仅在 ±200 pulse 软件范围内响应；按 BACK 必须立即停止。
6. 装连杆但不放球，手离开运动区域，核对正负方向、水平零点和机械限位。
7. 放球先测 Task 3 三轮；随后 Task 4 选 CONSERVATIVE 做 A-B。
8. Task 5 也从 CONSERVATIVE 开始，确认供电瞬态、相机帧率和 10 ms 循环后逐档升速。

## 6. BACK 安全动作

BACK 事件不等待串口应答：

1. TB6612 输出归零；
2. 发送 MaixCAM STOP；
3. MSPM0 直接发送 X42S `01 FE 98 00 6B`；
4. 清滚球与底盘任务状态；
5. 返回菜单。

软件急停不能替代物理总电源开关。调试时手不得进入曲柄、连杆、铰链和摆杆端部运动区。
