# 视觉循迹小车架构

## 当前数据流

```text
MaixCAM 识别钢球
  └─ UART2 115200 发送位置、尺寸、置信度
MSPM0G3507
  ├─ OLED 四键菜单选择任务
  ├─ 八路灰度循迹
  ├─ 视觉接近、2 s 盲走、轨迹倒放、重新捕线
  ├─ MPU6050/6500 航向测量与静止角度保持
  └─ 双编码器速度 PID 与里程计
```

系统不包含电磁铁和蓝牙控制。

## 菜单任务

| 菜单项 | 行为 |
|---|---|
| BALL VISION | 3 秒延迟后巡线；红框减速；绿框后视觉接近、盲走、倒退并重新找线 |
| ANGLE HOLD | 锁定当前航向，偏差超过 2.5°开始修正，回到 1°内停止 |
| LINE ONLY | 3 秒延迟后仅运行灰度巡线 |
| CALIBRATE YAW | 停车并重新执行静止零偏校准 |
| ODOMETER | 停车并显示累计里程 |

返回键始终作为停车键。

## 视觉状态

`IDLE → LINE → LOCK → APPROACH → CREEP → BACKTRACK → REACQUIRE → COMPLETE`。
重新捕线失败进入 `FAULT`。完成或故障后电机停车，由菜单选择下一项任务。

## 控制约束

- 主循环 10 ms，速度 PID 每 20 ms 更新。
- 视觉目标超过 200 ms 未更新即失效。
- 红框最低置信度 50%，巡线输出缩放至三分之一。
- 控制目标最低置信度 60%，且必须由 MaixCAM 标记为连续确认。
- 接近最长 7.5 s；视觉丢失连续 100 ms 后进入 11 RPM、2 s 盲走。
- 全白丢线按最后有效偏差搜索 200 ms，未恢复则停车。
