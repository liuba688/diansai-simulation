# MaixCAM 寻球小车接线与供电

本接线表依据本地原理图 `PCB/TI板卡/原理图文件/SCH_Schematic1_2026-06-13.pdf` 和当前代码引脚定义整理。

## 1. MaixCAM 与 MSPM0G3507

使用 PCB 上普通四针 `UART2` 接口，不使用带 12 V 的 UART3/UART5。

| MaixCAM | PCB / MSPM0G3507 | 作用 |
|---|---|---|
| A19 / UART1_TX | UART2 RX / PA24 | MaixCAM 发送目标 |
| A18 / UART1_RX | UART2 TX / PA23 | 小车回传状态 |
| GND | UART2 GND | 必须共地 |
| 不接 | UART2 +5V | MaixCAM 用 Type-C 供电时必须留空 |

PCB UART2 四针顺序按原理图为：

```text
1: +5V
2: GND
3: RX / PA24
4: TX / PA23
```

注意：

- UART 是交叉接法：TX 接对方 RX。
- MaixCAM GPIO 是 3.3 V 逻辑，禁止接入 5 V 或 12 V 信号。
- MaixCAM 可以先由 Type-C 单独供电，只要其 GND 与小车 GND 相连即可通信。
- 只做单向初测时，至少连接 `A19 → PA24` 和 GND；双向状态显示再连接 `PA23 → A18`。
- PA23 在核心板资料中属于特殊引脚。若小车状态始终无法回传，应按核心板原理图复核 R8、R9、C14、C15 的实际装配；这不影响 PA24 接收 MaixCAM 目标的单向链路。

## 2. 电磁铁驱动

当前代码使用 H55 排针第 8 路 `PB10`，高电平有效。

```text
PB10 ─────────────> 3.3 V 兼容 MOSFET 模块 IN
MSPM0 GND ────────> MOSFET 模块 GND
线圈电源负极 ─────> MOSFET 功率地/Source
线圈电源正极 ─────> 电磁铁正极
电磁铁负极 ───────> MOSFET 开关输出/Drain
```

具体端子名以购买的 MOSFET 模块丝印为准。若模块没有续流保护，在线圈两端并联续流二极管：

```text
二极管阴极（有色环）接线圈正极
二极管阳极接线圈负极
```

禁止：

- 电磁铁线圈直接接 PB10。
- 线圈电流经过 MSPM0 或 MaixCAM 的 3.3 V/5 V 引脚。
- 使用不支持 3.3 V 高电平可靠导通的 MOSFET 模块。
- 忽略线圈的额定电压、稳态电流和吸合瞬态。

建议在线圈功率回路加入保险丝和独立电源开关。MOSFET、导线、电源和接口额定电流均应高于实测线圈电流并留余量。

## 3. 推荐供电拓扑

```text
小车电池 ──> 小车 PCB / TB6612 / MSPM0
线圈适配电源 ──> 电磁铁 + MOSFET 功率回路
Type-C 5 V ──> MaixCAM

三路 GND 可靠共地
```

线圈电压若与小车电池不一致，应使用合适的降压/升压模块，不要靠串联电阻长期降压。MaixCAM Type-C、电机电源和线圈电源可以独立，但信号通信和 MOSFET 控制所涉及的地必须相连。

## 4. 上电前逐项检查

1. 断电状态下用万用表确认电源正负极没有短路。
2. 确认 UART2 的 `+5V` 没有接到 Type-C 供电中的 MaixCAM。
3. 确认 A19/A18 未接反，且没有接到 UART3/UART5 的 12 V 脚。
4. 先不接电磁铁线圈，用 LED 或万用表确认 PB10/MOSFET 输入开关逻辑。
5. 单独给线圈功率回路上电，检查 MOSFET、二极管、接头和导线温升。
6. 首次整车测试架空驱动轮，并准备能够立即断开电机和线圈电源的总开关。
